# My Yandex Code

A collaborative code editor with Google authentication, shareable project links, and real-time editing.

## Features

- Create personal projects
- Invite other users with one link
- Edit code together in real time
- See active collaborators inside the project
- Manage owned and shared projects separately

## Stack

- Frontend: React, Vite, Monaco Editor, Tailwind CSS
- Backend: NestJS, TypeORM, PostgreSQL, Socket.IO
- Collaboration: Yjs
